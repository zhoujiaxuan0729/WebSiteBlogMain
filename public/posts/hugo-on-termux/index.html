在 Termux 上用 Hugo 搭一个属于自己的轻量博客

2026-11-02 约 1 分钟读完 TermuxHugo

为什么选 Hugo

手机上资源有限，WordPress 那套 Nginx + MySQL + PHP 常驻起来内存就吃满了。Hugo 是 Go 写的单二进制，编译一次整个站只要几百毫秒，写完 Markdown 立刻能预览。

第一步：装 Hugo

pkg install git golang -y
# 下载 ARM64 扩展版
wget https://github.com/gohugoio/hugo/releases/download/v0.140.0/hugo_extended_0.140.0_linux-arm64.tar.gz
tar xzf hugo_extended_0.140.0_linux-arm64.tar.gz
chmod +x hugo
mv hugo $PREFIX/bin/

第二步：新建站点

hugo new site myblog
cd myblog
git init

第三步：写文章

hugo new posts/my-first-post.md

编辑 content/posts/my-first-post.md，把顶部 draft: true 改成 false。

第四步：本地预览

hugo server -D --bind 0.0.0.0

--bind 0.0.0.0 很关键，不然同局域网其他设备访问不到。

发布

hugo

编译产物在 public/ 目录，直接拖到 Cloudflare Pages 或 GitHub Pages 就行。
